# MARGA NANIME

Modern anime community website. Built with Next.js 14, React 18, TypeScript, Tailwind CSS, Framer Motion.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm start
```

## Deploy to Vercel
Push to GitHub and import the repo on [vercel.com](https://vercel.com). No env vars required.
